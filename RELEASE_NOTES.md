## NStorm 2 Mobile

Peluncur Android untuk menjalankan **Naruto Shippuden: Ultimate Ninja Storm 2 versi PC (NSUNS2.exe)** lewat Wine/Proton 9 + FEXCore/Box64 + DXVK + Mesa Turnip, dibangun di atas Winlator Cmod v13.1. Game tidak disertakan.

### Cara instal singkat
1. Unduh file `.apk` di bawah, instal (izinkan sumber tidak dikenal).
2. Buka aplikasi → beri izin **Akses semua file** → tunggu pemasangan sistem (sekali saja).
3. Salin file game PC ke `/storage/emulated/0/nstorm2/` (harus ada `NSUNS2.exe`).
4. Ketuk **MAINKAN**. Save tersimpan di `/storage/emulated/0/nstorm2/saves/`.

### Penting
- Versi Steam memerlukan klien Steam untuk Windows yang berjalan di dalam aplikasi (mode "Melalui klien Steam"). Tidak ada bypass DRM.
- Belum diuji di perangkat fisik oleh pembuat build; mohon laporkan hasil di Issues.
- Setelan bawaan dioptimalkan untuk Xiaomi Pad 6 (Snapdragon 870 / Adreno 650 + Turnip).

Verifikasi: cocokkan SHA-256 dengan file `.sha256` yang menyertai APK. Panduan lengkap ada di README.
